# DSA 新闻采集与盘中监控

## 当前实现

新闻模块第一阶段使用免费 RSS 作为基础数据源：

- 新浪财经：财经要闻、股票要闻、股市及时雨
- 中国新闻网：财经新闻

RSS 采集不需要 API Key。原有 Bocha、Tavily、SerpAPI 搜索服务仍可作为补充数据源。

## 一次性采集

在仓库根目录执行：

```bash
python -m src.news_feed --once
```

默认 SQLite 文件为 `./data/news_monitor.db`。可以通过环境变量指定持久化路径：

```bash
NEWS_DATABASE_PATH=/var/lib/dsa/news_monitor.db python -m src.news_feed --once
```

一次性采集只写入数据库，不触发飞书通知。

## 盘中监控

在已经部署仓库代码、安装 requirements.txt 依赖并配置通知渠道的主机上执行：

```bash
NEWS_DATABASE_PATH=/var/lib/dsa/news_monitor.db \
python -m src.news_feed --watch --interval 180
```

- 默认每 180 秒轮询一次，可通过 `--interval` 调整，最小 60 秒。
- 仅在北京时间工作日 08:45–11:35、12:55–15:10 轮询。
- 当前只使用星期和时间判断交易窗口，尚未接入 A 股官方交易日历；节假日工作日可能仍会轮询。
- P0 规则目前只根据标题中的重大合同、重大资产重组、立案调查、行政处罚、业绩预告、业绩快报、停牌、退市风险、重大诉讼等关键词筛选。
- 只有发布时间落在最近两个轮询周期内的 P0 新闻才会尝试推送。
- 告警按原文 URL 去重；推送失败会释放去重记录，允许下一轮重试。
- 盘中轮询不调用大模型，避免持续消耗 AI Token。
- P0 只是规则命中提醒，不代表新闻已核实或必然影响股价。

## 数据与报告

新闻原始记录保存在 `news_articles` 表中，按 URL 去重，保留来源、分类、标题、摘要、原文链接、源站发布时间、采集时间和内容哈希。P0 通知去重记录保存在 `news_alerts` 表中。

大盘复盘和个股分析均会尝试从 RSS 中匹配新闻。个股 RSS 匹配当前使用股票代码或股票简称在标题/摘要中进行精确包含匹配；尚未建立公司别名、子公司和产业链知识图谱，召回率有限。

大盘复盘报告新增新闻与事件驱动章节，展示来源、发布时间和原文链接。AI Prompt 要求区分已确认事实与媒体推测，并结合行情验证；无 AI 时的模板报告只做新闻摘要，不会虚构影响判断。

## 当前边界与后续阶段

1. 当前 RSS 来源主要是媒体新闻，不等于上市公司官方公告。巨潮资讯、上交所、深交所公告采集仍需单独实现和测试。
2. 当前盘中 P0 告警是关键词规则，不是 AI 事件分析；下一阶段再加入事件分类、公司/行业关联和重要性评分。
3. 当前尚未接入官方交易日历、节假日识别、新闻事件聚合和跨来源转载聚类。
4. ECS 常驻监控尚未部署。运行 `--watch` 需要把仓库代码部署到持久运行主机，并为进程配置 systemd 和持久化数据库目录；仅修改 GitHub 仓库不会自动在 ECS 启动进程。
5. 真实 RSS 采集、通知推送和盘中连续运行尚未执行，需在 CI 与隔离环境测试通过后再部署。
